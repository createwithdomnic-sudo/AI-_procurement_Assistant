# 🤖 AI Procurement Assistant

An AI-inspired procurement analytics application built using **Python, Flask, JavaScript, HTML, CSS, and REST APIs**, designed around **SAP MM procurement workflows**.

The application helps users monitor purchase orders, identify overdue transactions, analyze procurement risks, view supplier information, and interact with a procurement assistant through an interactive dashboard.

---

## 🚀 Features

- 📊 Procurement analytics dashboard
- 📦 Purchase order monitoring
- ⚠️ Overdue purchase order detection
- 🚨 Procurement risk analysis
- 🏢 Supplier information
- 💰 Total procurement value calculation
- 🤖 Procurement assistant
- 🔗 REST API integration
- 📱 Responsive web interface
- 🔍 Purchase order search and analysis
